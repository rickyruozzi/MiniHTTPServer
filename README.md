Il seguente progetto è realizzato puramente a scopo didattico, se lo si vuole utilizzare basterà scaricare i sorgenti, compilarli sul proprio os specificandolo nel modo seguente -> "make linux" per distribuzioni Linux o "make windows", ovviamente servirà creare un proprio db che rispecchi la struttura desiderata, a meno che non si vogliano personalizzare le query e modificarne sostanzialmente il funzionamento.
Servirà aggiungere un file chiamato "credentials.txt" che specifichi nell'ordine corretto le informazioni necessarie per la connessione. 
Il progetto è stato realizzato in poco tempo anche grazie al riutilizzo di funzioni già precedentemente implementate con i doverosi adattamenti e all'uso dell'IA per i noiosi compiti di parsing, html formatting e json string extraction, oltre che per controllare il codice scritto prima di alcuni commit.
